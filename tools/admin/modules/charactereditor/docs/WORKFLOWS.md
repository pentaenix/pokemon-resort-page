# Workflows

## Prepare and assign a Platinum sheet

1. Go to **Sheets**.
2. Import the PNG sheet.
3. Click **Apply Platinum Template**.
4. Confirm the prepared sheet is selected.
5. Click **Save sheet**.
6. Choose a character.
7. Click **Save assignment**.
8. Click **Populate character from saved sheet**.

## Use manual extraction

Open **Advanced tools** in the sheet mapper, click a grid cell, set a label and direction, then extract only that cell. This is for one-off custom poses, not the default workflow.

## Train and generate an action

1. Add at least one base sprite and matching action sprite.
2. Go to **Actions**.
3. Create training pairs with the same label, such as `fishing_right`.
4. Train that label.
5. Go to **Generate** and apply the label to a compatible base sprite.

## Edit pixels

Open a sprite in **Editor**. Use zoom and grid for cleanup. Save creates a generated copy; it does not overwrite the source.
